# Personal Portfolio Website

This is a clean and scalable portfolio template built with **Jekyll** and hosted using **GitHub Pages**.  
It uses the elegant **Minimal Mistakes** theme.

## 🌐 Live Demo
Once deployed: https://Ahpatsum15.github.io

## 📁 Features

- Elegant homepage
- About section with downloadable CV
- Project showcase with GitHub links
- Blog system categorized by domain (ML, Cryptography, CP)
- Easy to scale and customize
